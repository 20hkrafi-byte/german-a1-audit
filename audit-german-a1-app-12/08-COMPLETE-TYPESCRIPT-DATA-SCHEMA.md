## 4. Question

```typescript
interface Question {
  q:    string;              // Question text (German or English)
  bn:   string;              // Bangla question translation
  opts: [string, string][];  // Options: [[German text, Bangla text], ...]
  a:    number;              // Correct answer index (0-based)
  key:  string;              // Answer keyword(s) for Learn Mode hint
  e:    string;              // Evidence line from source text
  x:    string;              // Explanation text
}
```

**Question counts by section:**
| Section | Questions | Options per Q |
|---|---|---|
| Hören | 5 | 3 |
| Lesen | 5 | 2 (Richtig/Falsch) |
| Schreiben | 6 | 3 |

## 7. Form Trainer Data

```typescript
// Golden Rules
type FormRule = [
  string,  // Rule name (English)
  string,  // Rule detail (English)
  string   // Rule detail (Bangla)
];
// const FORM_RULES: FormRule[]  (8 items)

// Field Bank
type FieldDefinition = [
  string,  // German field name (e.g., "Familienname")
  string,  // English meaning
  string,  // Bangla meaning
  string   // Example value
];
// const FIELD_BANK: FieldDefinition[]  (24 items)

// Form Exercise
interface FormExercise {
  topic:  string;              // "Deutschkurs Anmeldung"
  tag:    string;              // "Course registration"
  text:   string;              // Source text (German)
  fields: [string, string][];  // [[fieldLabel, correctAnswer], ...]
}
// const FORMS: FormExercise[]  (12 items)

// Mini Quiz
type MiniQuiz = [
  string,  // Source text snippet
  string,  // Field name to identify
  string   // Correct answer
];
// miniQuizzes() uses 8 MiniQuiz items

// Error Lab Row
type ErrorRow = [
  string,  // Wrong answer
  string,  // Correct answer
  string,  // Explanation (English)
  string   // Explanation (Bangla)
];
// errorLab() uses 6 ErrorRow items
```
