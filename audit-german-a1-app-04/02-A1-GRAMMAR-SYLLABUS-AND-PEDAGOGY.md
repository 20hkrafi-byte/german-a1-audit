## 1. App #04 Official Description

> **"Transform patterns, arrange words and produce new beginner sentences from a clear model."**

`[VERIFIED LIVE]` — Extracted from `<article class="ss-app">` at line 1371 of `self-study.html`.

### 1.1 Pedagogical Verb Decomposition

| Verb Phrase | Implied Drill Type | German Skill Target |
|-------------|-------------------|---------------------|
| "Transform patterns" | Pattern transformation (declarative → interrogative, positive → negative, singular → plural) | V2 word order, negation with `nicht`/`kein`, question inversion |
| "Arrange words" | Word-order reordering / drag-and-drop sentence assembly | V2 rule, Satzklammer (sentence bracket), time-manner-place ordering |
| "Produce new beginner sentences" | Sentence generation from templates, fill-in-the-blank, guided free production | Active sentence construction using learned grammar patterns |
| "From a clear model" | Model sentence provided → learner applies pattern to new lexical context | Scaffolded production via worked examples |

### 1.2 Position in 12-App A1 Sequence

App #04 is the **first app in Phase 2 — Build** ("Core grammar, verbs and sentence patterns"), following three Phase 1 apps focused on sounds, pronunciation, and listening/speaking. This positioning means:

- **Prerequisite skills:** Alphabet recognition, basic phonetics, initial vocabulary (≈ 200–300 words), basic listening comprehension
- **What App #04 introduces:** The first formal grammar instruction — word order rules, case system foundations, verb conjugation patterns, sentence structure
- **What follows:** App #05 (Reading Workshop) and App #06 (Writing Lab) build on the grammar patterns established in App #04

### 5.2 Grammar Teaching Methodology: "Rule → Structure → Example → Mistake"

The shared platform uses a consistent 4-box deductive grammar presentation model:

| Box Type | CSS Class | Purpose | Example |
|----------|-----------|---------|---------|
| **Rule Box** | `.rulebox` | States the grammar rule clearly | "The verb is always in position 2 in a German main clause." |
| **Structure Box** | `.structurebox` | Shows the pattern / formula | "**Subject** + **Verb (P2)** + **Object/Complement**" |
| **Example Box** | `.examplebox` | Provides worked examples with audio | "Ich lerne Deutsch. / Am Montag gehe ich zur Schule." |
| **Mistake Box** | `.mistakebox` | Shows common errors with corrections | "❌ Am Montag ich gehe zur Schule. ✅ Am Montag gehe ich zur Schule." |

Additional elements:
- **Mini Box** (`.minibox`): Short notes, tips, or exceptions
- **Grammar Tables** (`<table>`): Conjugation tables, case tables, pronoun charts
- **Audio Buttons**: `onclick="speakGerman('...')"` on individual sentences inside grammar boxes

## 6. How App #04 Bridges Recognition to Production

### 6.1 Input–Output Skill Progression

| Prior Apps (#01–#03) | App #04 Transition | Skill Type |
|----------------------|--------------------|------------|
| Hear sounds → recognize | Understand rules → apply | Receptive → Productive |
| Repeat pronunciation | Construct sentences | Imitation → Creation |
| Memorize vocabulary | Use vocabulary in grammar patterns | Isolated → Contextual |
| Listen & respond | Read rules & produce sentences | Oral → Written + Oral |

### 6.2 Grammar-Vocabulary Integration

App #04 takes the ≈ 200–300 vocabulary items learned in Apps #01–#03 and teaches learners how to:
1. **Assign cases**: Which case does this noun take? (Nominativ vs. Akkusativ)
2. **Conjugate verbs**: How does this verb change for `ich` vs. `du` vs. `er/sie/es`?
3. **Build word order**: Where does each element go in the sentence?
4. **Negate correctly**: `nicht` or `kein`?
5. **Ask questions**: How to invert for yes/no questions, how to use W-words
6. **Use modals**: How to add `können`, `müssen`, etc. to express ability, obligation
7. **Handle separable verbs**: Where does the prefix go?
