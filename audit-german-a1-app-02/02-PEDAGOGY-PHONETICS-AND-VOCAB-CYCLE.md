## 5. How Pronunciation Is Taught Across Shared Codebases

### 5.1 English Phonetic Respelling `[VERIFIED FROM SHARED CODEBASE: german-directions-html]`

The German Directions bundle uses **English-approximation phonetic respelling** with stress marking via CAPITALS:

| German Word | Phonetic Respelling | Stress Pattern |
|-------------|---------------------|----------------|
| rechts | `rekhts` | Single syllable |
| links | `links` | Single syllable |
| geradeaus | `ge-RAH-de-ows` | Stress on 2nd syllable (CAPITALS) |
| zurück | `tsu-RÜK` | Stress on 2nd syllable (CAPITALS) |

**Key observations:**
- Hyphen-delimited syllable breaks
- UPPERCASE for stressed syllable
- German special characters retained where needed (Ü in `tsu-RÜK`)
- English-readable approximation (not IPA)

## 7. Repetition Loop Mechanics `[VERIFIED FROM SHARED CODEBASE: german-directions-html]`

### 7.1 Auto-Drill Sequence (`playAuto()`)

```
render card → speak word → 3s pause → speak phrase → 3s pause → speak word again → 2s pause → next card
```

This creates a **three-exposure repetition** per card:
1. **First exposure:** Hear the word (isolated)
2. **Second exposure:** Hear the word in context (phrase)
3. **Third exposure:** Hear the word again (reinforcement)

### 7.2 French Opposite Drill Sequence `[VERIFIED FROM SHARED CODEBASE: french-opposite-html]`

```
EN/BN command prompt → thinking gap → FR command → animation → gap → FR repeat → next
```

Gap durations scale with speed setting: `[4500, 3800, 3200, 2500, 1800]` ms

### 7.3 Timed Drill Mode

5-minute countdown drill (`startFive()`) runs the auto-drill loop with a timer display showing `MM:SS` remaining, auto-stopping when time expires.
