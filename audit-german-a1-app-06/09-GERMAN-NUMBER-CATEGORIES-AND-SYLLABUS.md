## 2. Five Number Categories (from App Description)

The description explicitly names **5 categories**. Each is documented below with the projected German A1 scope.

### 2.1 Category 1: Age (Alter)

**Range:** 0–120 (practical: 1–99)

| Example Value | German | Phonetic (Proj.) | English | Bangla (Proj.) |
|:-------------:|--------|-------------------|---------|----------------|
| 5 | fünf Jahre alt | FUENF YAH-reh alt | five years old | পাঁচ বছর বয়সী |
| 27 | siebenundzwanzig Jahre alt | ZEE-ben-oont-TSVAN-tsig YAH-reh alt | twenty-seven years old | সাতাশ বছর বয়সী |
| 83 | dreiundachtzig Jahre alt | DRAY-oont-AHKHT-tsig YAH-reh alt | eighty-three years old | তিরাশি বছর বয়সী |

**Key Vocabulary:**
- **Jahre** (YAH-reh) = years — বছর
- **alt** (alt) = old — বয়সী / পুরানো
- **Wie alt bist du?** = How old are you? — তোমার বয়স কত?
- **Wie alt sind Sie?** = How old are you? (formal) — আপনার বয়স কত?
- **Ich bin … Jahre alt.** = I am … years old. — আমার বয়স … বছর।

**A1 Relevance:** "Introducing yourself" is core A1 — age is asked in every Goethe A1 exam.

### 2.2 Category 2: Prices (Preise)

**Range:** 0,10 € – 999,99 € (practical A1: 0,50 € – 99,99 €)

| Example Value | German | English | Bangla (Proj.) |
|:-------------:|--------|---------|----------------|
| 0,50 € | fünfzig Cent | fifty cents | পঞ্চাশ সেন্ট |
| 3,50 € | drei Euro fünfzig | three euros fifty | তিন ইউরো পঞ্চাশ |
| 12,99 € | zwölf Euro neunundneunzig | twelve euros ninety-nine | বারো ইউরো নিরানব্বই |
| 149,00 € | (ein)hundertneunundvierzig Euro | one hundred forty-nine euros | একশো উনপঞ্চাশ ইউরো |

**Key Vocabulary:**
- **Euro** (OY-ro) = euro — ইউরো
- **Cent** (TSENT) = cent — সেন্ট
- **kosten** (KOS-ten) = to cost — দাম / খরচ হওয়া
- **Was kostet das?** = What does it cost? — এটার দাম কত?
- **Das kostet … Euro.** = It costs … euros. — এটার দাম … ইউরো।

**German Number Format:**
- Decimal separator: **comma** (3,50 not 3.50)
- Thousands separator: **period** (1.250,00 not 1,250.00)
- Currency symbol position: after number (3,50 €)

### 2.3 Category 3: Phone Numbers (Telefonnummern)

**Range:** 7–11 digit sequences read digit-by-digit

| Example Value | German Reading | Bangla (Proj.) |
|:-------------:|----------------|----------------|
| 0151 2345 6789 | null eins fünf eins – zwei drei vier fünf – sechs sieben acht neun | শূন্য এক পাঁচ এক – দুই তিন চার পাঁচ – ছয় সাত আট নয় |
| 030 1234567 | null drei null – eins zwei drei vier fünf sechs sieben | শূন্য তিন শূন্য – এক দুই তিন চার পাঁচ ছয় সাত |
| +49 30 12345 | plus neun und vierzig – drei null – eins zwei drei vier fünf | +৪৯ – তিন শূন্য – এক দুই তিন চার পাঁচ |

**Key Vocabulary:**
- **die Telefonnummer** = the telephone number — টেলিফোন নম্বর
- **die Handynummer** = the mobile number — মোবাইল নম্বর
- **die Vorwahl** = the area code — এরিয়া কোড
- **Wie ist Ihre Telefonnummer?** = What is your phone number? — আপনার ফোন নম্বর কত?
- **Meine Nummer ist …** = My number is … — আমার নম্বর হলো …

**German Phone Formats:**
- Mobile: 0151, 0152, 0160, 0170, 0171, 0172, 0176, 0177, 0178, 0179 + 7 digits
- Landline (Berlin): 030 + 7–8 digits
- Landline (Munich): 089 + 7–8 digits
- International prefix: +49

**Special note:** German reads phone numbers **digit-by-digit**, not as compound numbers. "2" in phone numbers is often said as "zwo" (not "zwei") to avoid confusion with "drei" on the phone.

### 2.4 Category 4: Quantities (Mengen)

**Range:** 1–1000+

| Example Value | German | English | Bangla (Proj.) |
|:-------------:|--------|---------|----------------|
| 3 Äpfel | drei Äpfel | three apples | তিনটা আপেল |
| 250 g | zweihundertfünfzig Gramm | two hundred fifty grams | আড়াইশো গ্রাম |
| 1 kg | ein Kilogramm | one kilogram | এক কিলোগ্রাম |
| 2 Liter | zwei Liter | two liters | দুই লিটার |
| 500 ml | fünfhundert Milliliter | five hundred milliliters | পাঁচশো মিলিলিটার |
| 6 Stück | sechs Stück | six pieces | ছয়টা / ছয় টুকরা |

**Key Vocabulary:**
- **Gramm** (g) — গ্রাম
- **Kilogramm** (kg) — কিলোগ্রাম
- **Liter** (l) — লিটার
- **Stück** = piece — টুকরা / টা
- **Wie viel?** = How much? — কতটুকু?
- **Wie viele?** = How many? — কতগুলো?

### 2.5 Category 5: Addresses (Adressen)

**Range:** Hausnummer 1–999 + PLZ 10000–99999

| Example Value | German | Bangla (Proj.) |
|:-------------:|--------|----------------|
| Hauptstraße 42 | Hauptstraße zweiundvierzig | হাউপ্টস্ট্রাসে বিয়াল্লিশ |
| 10115 Berlin | eins-null-eins-eins-fünf Berlin | ১০১১৫ বার্লিন |
| Mozartstraße 7, 80336 München | Mozartstraße sieben, acht-null-drei-drei-sechs München | মোৎসার্টস্ট্রাসে সাত, ৮০৩৩৬ ম্যুনশেন |

**Key Vocabulary:**
- **die Straße** = the street — রাস্তা
- **die Hausnummer** = the house number — বাড়ি নম্বর
- **die Postleitzahl (PLZ)** = the postal code — পোস্টকোড
- **Wo wohnst du?** = Where do you live? — তুমি কোথায় থাকো?
- **Ich wohne in der …straße …** = I live at … street … — আমি …স্ট্রাসে …-এ থাকি।

**German Address Format:**
- Street name + house number (not number first like English)
- Hausnummer: 1–999 (read as compound number, not digit-by-digit)
- PLZ: 5-digit postal code (read digit-by-digit: "eins null eins eins fünf")
- Format: `Straßenname Hausnummer, PLZ Stadt`

### 4.2 Random Generation Per Category (Projected)

```javascript
// PROJECTED generator functions — NOT from live source
function randomAge() {
  const age = Math.floor(Math.random() * 99) + 1;  // 1-99
  return item(String(age), `${numToGerman(age)} Jahre alt.`, ...);
}

function randomPrice() {
  const euros = Math.floor(Math.random() * 100);     // 0-99
  const cents = Math.floor(Math.random() * 100);     // 0-99
  const formatted = `${euros},${String(cents).padStart(2,'0')} €`;
  return item(formatted, `${numToGerman(euros)} Euro ${numToGerman(cents)}`, ...);
}

function randomPhone() {
  const prefix = ['0151','0152','0160','0170','0176'][Math.floor(Math.random()*5)];
  const digits = Array.from({length:7}, () => Math.floor(Math.random()*10));
  return item(prefix + ' ' + digits.join(''), ...);
}

function randomQuantity() {
  const qty = [1,2,3,5,10,12,20,50,100,250,500,1000][Math.floor(Math.random()*12)];
  const unit = ['Gramm','Kilogramm','Liter','Stück','Packung'][Math.floor(Math.random()*5)];
  return item(`${qty} ${unit}`, `${numToGerman(qty)} ${unit}`, ...);
}

function randomAddress() {
  const hausNr = Math.floor(Math.random() * 200) + 1;
  const plz = String(Math.floor(Math.random() * 90000) + 10000);
  return item(`...straße ${hausNr}, ${plz}`, ...);
}
```

## 5. German Number Pronunciation Challenges for Bengali Speakers

### 5.1 Sounds Not Present in Bangla

| German Sound | IPA | Challenge for Bengali Speakers |
|-------------|-----|-------------------------------|
| **z** (ts) in "zehn", "zwei" | /ts/ | No /ts/ affricate in Bangla |
| **ü** in "fünf", "fünfzig" | /yː/ | No front rounded vowels in Bangla |
| **ö** in "zwölf" | /øː/ | No front rounded vowels in Bangla |
| **ch** in "acht", "achtzig" | /x/ or /ç/ | Bangla has /tʃ/ but not /x/ |
| **-ig** suffix in "zwanzig" | /ɪç/ | Often mispronounced as /ɪg/ |

### 5.2 Compound Number Reversal

Bangla and English both say tens first ("twenty-seven" / "সাতাশ"), but German reverses: "siebenundzwanzig" (seven-and-twenty). This is a major confusion point.

| Order | Language | "27" |
|:-----:|----------|------|
| tens-first | English | twenty-seven |
| unique | Bangla | সাতাশ (sātāsh) |
| ones-first | German | siebenundzwanzig |

### 5.3 Similar-Sounding Numbers

| Numbers | German | Risk |
|---------|--------|------|
| 2 vs 3 | zwei vs drei | Rhyme — "zwo" used on phone |
| 13 vs 30 | dreizehn vs dreißig | Stress position |
| 14 vs 40 | vierzehn vs vierzig | Stress position |
| 15 vs 50 | fünfzehn vs fünfzig | Stress position |
| 16 vs 60 | sechzehn vs sechzig | Very similar |
| 17 vs 70 | siebzehn vs siebzig | Very similar |
